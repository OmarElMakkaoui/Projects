# Data

The study used daily NO₂ concentrations from the Airparif monitoring station in
Paris 13e, supplied by the project client, merged with daily observations from the
Météo-France station at Parc Montsouris (the nearest station reporting wind). That
extraction is not redistributable, so it is not in this repository.

`synthetic_no2_paris.csv` is generated by `make_synthetic_data.py`. It has the same
schema, so the whole pipeline runs, but its values are **synthetic**, with a planted
trend and planted lockdown effects used to check that the pipeline recovers them.

## Schema expected by `airquality.load_data`

One row per day; rows with a missing value in any required column are dropped.

| Column | Unit | Description | Source |
|---|---|---|---|
| `AAAAMMJJ` | date (`YYYY-MM-DD`) | day | — |
| `CNO2` | µg/m³ | daily mean NO₂ concentration | Airparif |
| `RR` | mm | daily precipitation | Météo-France |
| `TM` | °C | daily mean temperature | Météo-France |
| `FFM` | m/s | daily mean wind speed | Météo-France |
| `DXY` | degrees, 0–360 | direction of the daily maximum wind | Météo-France |

`TN` / `TX` (daily min/max temperature) may be present and are ignored.
